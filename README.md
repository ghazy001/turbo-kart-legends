# Turbo Kart Legends — Preproduction Starter Pack
This package contains **planning documents and Codex instructions**, not a built game.

- `GAME_DESIGN.md` — concept, mechanics, tracks, experience, risks.
- `ARCHITECTURE.md` — technical design, systems, data, physics and testing.
- `ROADMAP.md` — milestones, tasks and acceptance criteria.
- `AGENTS.md` — persistent Codex project instructions.
- `CODEX_M1_PROMPT.md` — paste into Codex to build the first playable milestone.

## Use with Codex
1. Create a new folder/repository called `turbo-kart-legends`.
2. Copy all six Markdown documents into the repo root.
3. Open the folder in VS Code / Codex.
4. Paste the entire contents of `CODEX_M1_PROMPT.md` as your task prompt.
5. Inspect the generated game and have Codex fix any failures until the milestone checklist passes.

The Milestone 1 prompt explicitly excludes AI, power-ups, multiplayer and backend work, to keep the initial goal achievable.
